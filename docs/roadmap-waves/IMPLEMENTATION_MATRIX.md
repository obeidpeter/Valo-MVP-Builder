This matrix records the authority actually delivered across the roadmap releases, including the five-capability third wave. “Integrated” means the route or browser surface is wired into Valo with its stated guards; it does not imply model execution, autonomous action, external submission, package release, cross-tenant learning, or production deployment verification.

## Cross-wave release rules

- Tenant, resource, role, direct-membership, current-user, optimistic-concurrency, private-cache, retention, and immutable-project boundaries remain authoritative even when a UI control is hidden.
- The consolidated OpenAPI publishes the public roadmap operations and generated React/Zod clients. The internal worker control surface remains absent by design.
- Provider calls, scraping, production AI activation, autonomous submission, automatic pricing, payment execution, legal decisions, and destructive privacy actions are never inferred from an implemented evidence workflow.
- Third-wave deterministic validation, review, assembly, rehearsal, and portfolio projections never substitute for named evidence approval, independent QA, package sign-off, portal operation, client-confirmed outcome evidence, or deployment verification.
- PostgreSQL-backed retention/export rehearsals require the CI PostgreSQL 16 environment. Browser test execution must run in CI when the local Windows Rollup optional binary is unavailable.
